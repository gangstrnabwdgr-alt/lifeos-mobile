LIFEOS — MOBILE PWA

این بسته فقط برای نصب LifeOS روی موبایل آماده شده است.

نکته مهم:
- برای Install App واقعی، سایت باید از HTTPS باز شود.
- Android/Chrome: منوی ⋮ → Install app
- iPhone/Safari: Share → Add to Home Screen
- داده‌های LifeOS در خود دستگاه ذخیره می‌شوند و برای استفاده شخصی نیازی به اتصال Windows ندارند.

این بسته را روی یک هاست HTTPS قرار دهید و index.html را در ریشه سایت نگه دارید.
